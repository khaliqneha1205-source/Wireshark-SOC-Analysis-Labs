
# Lab 03: Identify the Attacker's IP Address

## Overview
This lab focused on investigating network traffic using Wireshark to identify the IP address of an attacker. The main purpose was to understand how suspicious network communication can be examined through captured packets.

## Objectives
- Understand how IP addresses appear in captured network traffic.
- Identify suspicious source and destination IP addresses.
- Investigate network packets to trace the attacker's IP.
- Develop basic network investigation skills.

## Activities Performed
- Opened and analyzed the provided network packet capture.
- Examined packet details and IP address information.
- Inspected source and destination addresses.
- Investigated suspicious communication patterns.
- Identified the attacker's IP address from the captured traffic.

## Tools Used
- Wireshark
- Network Packet Capture (PCAP)

## Skills Gained
- IP Address Identification
- Network Traffic Analysis
- Packet Inspection
- Source and Destination Analysis
- Basic Threat Investigation

## Learning Outcome
Developed practical understanding of how to investigate captured network traffic and identify a potential attacker through IP address analysis.
